Qué lleva el sitio, por dentroWhat's inside, under the hood

ConceptoConcept

No es una lista de proyectos: es un selector de personaje. Tres facetas —3D & IA, Software, Hotel Tech— giran en una rueda fija en pantalla, cada una con su propio degradado, su propio modelo 3D y sus misiones reales sacadas del CV, sin inventar un solo puesto.

Not a project list — a character select screen. Three facets — 3D & AI, Software, Hotel Tech — spin on a fixed wheel, each with its own gradient, its own 3D model, and real missions pulled straight from the résumé, no invented job titles.

Motor visualRendering engine

Three.js + React Three Fiber + drei para toda la escena. El sitio detecta si el dispositivo es móvil, la ventana es angosta o el hardware es débil, y sirve texturas y sombras más livianas sin que nadie lo pida.

Three.js + React Three Fiber + drei for the whole scene. The site detects a mobile device, a narrow window, or weak hardware, and quietly serves lighter textures and shadows — no setting to flip.

Narrativa y scrollStory & scroll

GSAP + ScrollTrigger maneja una línea de tiempo maestra; Lenis suaviza el scroll compartiendo el mismo "tick". La cámara hace un solo recorrido continuo, sin cortes entre secciones.

GSAP + ScrollTrigger drives one master timeline; Lenis smooths the scroll, sharing the same tick. The camera runs a single continuous take, no cuts between sections.

Control por gestosHand-gesture control

MediaPipe Tasks Vision, corriendo en el navegador, sin backend: reconoce gestos en vivo desde la cámara y gira la rueda de personaje.

MediaPipe Tasks Vision, running entirely in the browser, no backend: reads live gestures from the camera and spins the character wheel.

Gogeta SSJ4

Escaneo fotogramétrico hecho con el celular, decimado y montado con material PBR real —difuso, normales, rugosidad y metalicidad por separado, no una textura de relleno—, comprimido con Draco.

A phone-made photogrammetry scan, decimated and rigged with a real PBR material — separate diffuse, normal, roughness and metalness maps, not a placeholder texture — compressed with Draco.

Cajón de figuras 3D3D figure drawer

Diez piezas generadas con Meshy AI, optimizadas con glTF-Transform (meshopt + WebP a 1024px). Carrusel tipo selector de personaje, con precarga de las dos figuras vecinas.

Ten pieces generated with Meshy AI, optimized with glTF-Transform (meshopt + WebP at 1024px). A character-select-style carousel that preloads the two neighboring figures.

Islas de Aether

Motor propio en canvas 2D, sin WebGL ni una sola textura: todo dibujado con glifos ASCII, z-buffer propio, corriendo en un Web Worker aparte del hilo principal.

A custom canvas-2D engine, no WebGL, no textures at all: everything drawn in ASCII glyphs, its own z-buffer, rendering inside a Web Worker off the main thread.

Honestidad radicalRadical honesty

Cada captura es real y cada enlace fue comprobado uno por uno. Las barras de habilidad muestran solo porcentajes reales del CV — si una faceta no tiene datos, el sitio lo admite en vez de rellenar.

Every screenshot is real, every link was checked one by one. Skill bars show only real percentages from the résumé — if a facet has no data yet, the site says so instead of padding the number.

InfraestructuraInfrastructure

Cero backend, cero base de datos. CI/CD con GitHub Actions: cada push a main compila y despliega solo a GitHub Pages. El contenido —personajes, capítulos, proyectos— vive en archivos de datos tipados, separado de la interfaz.

Zero backend, zero database. CI/CD with GitHub Actions: every push to main builds and deploys straight to GitHub Pages. Content — characters, chapters, projects — lives in typed data files, separate from the UI.
